#  NeuroCart – AI Powered Student Marketplace

##  Idea
NeuroCart is an AI-driven platform that helps students discover the best learning resources through smart recommendations, comparisons, and a chatbot interface.

##  Features
- AI Chatbot for product recommendations
- Product comparison system
- Student marketplace (notes, books, digital resources)
- Personalized dashboard
- Modern UI with dark AI theme

##  Future Scope
- AI Study Plan Generator
- Weakness Detection System
- Career Guidance AI

##  Tech Stack
- Frontend: React
- Backend: Node.js
- AI: Gemini API
